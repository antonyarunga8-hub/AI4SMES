# AI4SMEs Africa — Building Africa's AI Business Operating System

> Empowering African Small and Medium Enterprises (SMEs) with intelligent digital tools to automate customer service, bookkeeping, digital marketing, lead generation, business analytics, and WhatsApp-driven business operations.

---

## 🌟 Executive Summary & Vision

**AI4SMEs Africa** is a Pan-African technology platform designed to democratize Artificial Intelligence for millions of African entrepreneurs. By acting as a virtual business team, the platform helps SMEs improve productivity, eliminate manual paperwork, lower operational costs, and accelerate business growth.

## 🚀 Core Platform Modules

1. **Jambo AI Voice & Text Assistant**: Multilingual AI command bar supporting Swahili, English, Pidgin, and French.
2. **WhatsApp Business OS Simulator**: Interactive mobile emulator executing real business actions directly via WhatsApp messaging.
3. **AI Customer Service Agent**: 24/7 automated customer support, FAQ knowledgebase trainer, and automated appointment calendar scheduling.
4. **AI Bookkeeping Assistant**: Expense tracking, automated invoice generator with printable receipt formatting, cash flow health indicator, and mobile money reconciliation.
5. **AI Marketing Manager**: Social media copy generator for WhatsApp Status, Instagram, Facebook, and LinkedIn, campaign scheduler, and ROI analytics.
6. **AI Sales & Lead CRM**: Lead discovery, qualification scoring algorithm, stage management, and automated WhatsApp follow-ups.
7. **AI Business Advisor**: Revenue forecasting area charts, profit/loss breakdown, overall business health score, and prescriptive growth advice.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite 6, TailwindCSS 3
- **Icons**: Lucide React
- **Analytics & Data Visuals**: Recharts
- **Design Aesthetics**: Dark Mode, Glassmorphism, HSL Tailored Pan-African Color Palettes (Emerald Green, Amber Gold, Sapphire Blue, Violet)
- **Tooling & Build**: Node.js, npm, PostCSS, Autoprefixer

## ⚙️ Getting Started & Installation

### Prerequisites
- Node.js (v18 or higher)
- npm

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/antonyarunga8-hub/AI4SMES.git
cd AI4SMES

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
